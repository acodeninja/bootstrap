# Tennis refactoring

The Tennis kata, already solved, badly. Four implementations of the same scoring rules,
each unpleasant in a different way, and the job is to make one of them clear without
changing what it does.

## What it teaches

Reading code you did not write, extracting from it, and naming what comes out. The rules
are not the exercise — you already know them from Tennis — so everything you learn here
is about the shape of the code.

## Where it sits

No course uses it, because it needs a smelly implementation in the target language and
this repo ships none. It is the obvious follow-up to Tennis on any row with classes to
extract, and the starting code is MIT-licensed and translated into most mainstream
languages already.

## Not available in

The rows with nothing to refactor towards — the same list as Video Store. Also any row
Emily Bache's repo has no translation for, unless you port the smelly version yourself,
which is a reasonable exercise in its own right.

Starting code is linked, never copied into this repo.
