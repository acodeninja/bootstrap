# FizzBuzz

Print the numbers from 1 to 100, except that multiples of three print `Fizz`, multiples
of five print `Buzz`, and multiples of both print `FizzBuzz`.

It is the smallest problem that still needs a loop, a branch, division and string output
at once, which makes it the first kata where the language's own shape shows: what the
division operator is called, whether a branch can produce a value or only perform a
statement, and how text and numbers are joined.

## What it teaches

A loop with a counter, a branch per case, the remainder operator, and string output.
Your second test, and the first one with more than one case in it — which is where the
language's way of parametrising a suite earns its keep.

## Where it sits

Step 2 of every course, in all 64 languages. It assumes Hello, World.

## Not available in

Nothing blocks it.

`intercal` has no division operator and `befunge` has no strings, so for those two this is
a sitting's work rather than ten minutes. Their course sections say so.
